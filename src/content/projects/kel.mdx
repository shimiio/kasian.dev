## five tabs, every single time

**Working on [pare](/projects/pare/), every session started the same way: reopen five tabs, `cd` into the right folders.** There was no big breaking point, just a constant background annoyance. I stopped closing tabs. I even stopped shutting down my laptop: the power button sent it to hibernation, so I could come back to exactly where I left off.

Juggling two projects was worse. Switching meant setting up another terminal from scratch, and sometimes that alone killed the urge to switch.

## why not build my own?

I did try a ready-made one, Warp. It brought back my last directory and tabs, which helped, but it ate a lot of RAM, had no real projects to switch between, and some features were paid. After a while I stopped using it.

**So I thought: why not write my own?** In Rust, because I'd never touched it. I had about a year of C++ behind me, mostly practice projects, and everyone kept saying Rust is the safer replacement for it. A terminal in Rust sounded logical.

## a month alone, then Claude Code

For about a month, on and off, I worked on it alone, mostly figuring things out: how a PTY works, how a terminal draws, how a character ends up on screen. **What surprised me most were the cells.** The screen is a grid of them, each holding one character, and even the cursor is just a position moving between cells. You never notice that while using a terminal.

Drawing the actual output was where I got stuck. Rendering was harder than I expected, and somewhere around there I saw how big the whole job was. I got scared I'd spend forever on something that mattered only to me.

**So I brought in Claude Code, and we wrote the terminal together.** At first I tried to understand every line. The further we got, the harder that became, and in the end the agent wrote almost all of the code. Rendering is still mostly a black box to me.

I'm fine with that. I wanted a better tool for myself, and now I have one. On my own it would have taken months, and I'd have burned out before it worked like this.

## how it is now

**I use kel almost every day, for projects and as a plain terminal.** Each project is a saved set of tabs, so I come back to the same place instead of rebuilding it. [pare](/projects/pare/), [bob](/projects/discord-llm/), or something new: I jump between them in seconds.

It started as a tool for myself. But if the idea looks interesting to you, the code is open: take it and change it however you like.
